# SC 略語カード

情報処理安全確保支援士（SC）の略語と、ネットワーク基礎（TCP、UDP、ARP、DHCP、DNS など）を、1枚ずつめくる静的フラッシュカードです。

## 公開ページ

https://yamadalabojp.github.io/sc-acronym-flashcards/

## 使い方

1. トップページでカテゴリー（初期値は「すべて」）と出題順（初期値は「ABC順」。もう一方は「ランダム」）を選ぶ。「重要のみ」にチェックすると、その条件の重要語だけが出題と用語一覧の対象になる。初期状態はオフ。
2. 「スタート」で、その条件の1枚目が出る。分類はカード上部に最初から出る。画面のどこかをタップすると正式名称と一言定義を表示し、もう一度タップすると次のカードへ進む。同じ周回では同じカードを繰り返さない。一巡すると、ランダムは同じ分類のままシャッフルし、ABC順はその順のまま続く。
3. 「用語一覧」は、選んだカテゴリーを見出しにして、その中の略語を ABC順で並べる。「すべて」のときは全カテゴリーを見出し付きで並べる。問題画面と一覧のどちらからもトップへ戻れる。

ビルドは不要です。

```bash
python3 -m http.server 41731
```

ブラウザで http://127.0.0.1:41731 を開きます。

## データ

`data/sc-acronyms.csv`（列: 略語, 正式名称, 一言定義, 分類, 重要）が元データです。ページは同じ内容を埋め込んだ `data.js` を読みます。現在277語で、文言はCSVのままです。重要は 1 または 0 です。
