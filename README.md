# SC 略語カード

情報処理安全確保支援士（SC）の略語と、ネットワーク基礎（TCP、UDP、ARP、DHCP、DNS など）を、1枚ずつめくる静的フラッシュカードです。

## 公開ページ

https://yamadalabojp.github.io/sc-acronym-flashcards/

## 使い方

1. 大きく表示された略語を見て、正式名称を思い出す。
2. カードか「答えを見る」で、正式名称・一言定義・分類を表示する。
3. もう一度タップするか「次へ」で、答えを隠して次の略語へ進む。同じ周回では出た語を繰り返さない。115語を出し切るとシャッフルして次の周回に入る。

ビルドは不要です。

```bash
python3 -m http.server 41731
```

ブラウザで http://127.0.0.1:41731 を開きます。

## データ

`data/sc-acronyms.csv`（列: 略語, 正式名称, 一言定義, 分類）が元データです。ページは同じ内容を埋め込んだ `data.js` を読みます。用語の追加や言い換えはしていません。
